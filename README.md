# VIONEX - Smart Agriculture & Farm Management

This repository contains the complete source code for the VIONEX web and Android application.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
